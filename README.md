# 💄 AI-Driven Makeup Artist Booking Platform

An interactive full-stack web platform that combines AI-powered makeup style detection with makeup artist discovery, booking, product recommendations, and beauty tutorials.

## ✨ Features

- 🤖 AI-powered makeup style detection
- 💄 Makeup style classification
- 👩‍🎨 Makeup artist booking
- 🛍️ Product recommendations
- 📚 Style-based tutorials
- 🔐 User login and signup
- 🔥 Firebase integration
- 📱 Interactive and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- Firebase
- Machine Learning / Deep Learning
